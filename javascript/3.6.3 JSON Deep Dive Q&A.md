👉 Uses:

- `JSON.stringify()` → object → string
- `JSON.parse()` → string → object

# 🔹 Deep Dive Interview Q&A 🎯

---

## ❓1. What is JSON and why is it used?

👉 JSON (JavaScript Object Notation) is a **lightweight data format** used to exchange data between systems.

- It is language-independent
- Easy to read and parse
- Used in APIs, storage, configs

💡 WHY:

> It standardizes communication between frontend and backend

---

## ❓2. Difference between JSON and JavaScript object?

👉 JSON is a **string format**, JS object is a **runtime data structure**

```js
const obj = { name: "Dilip" }; // JS object
const json = '{"name":"Dilip"}'; // JSON string
```

💡 Key difference:

- JSON requires **double quotes**
- JS object allows more flexibility

---

## ❓3. What does JSON.stringify do?

👉 Converts JS object → JSON string

- Removes unsupported values
- Prepares data for network/storage

💡 Used in:

- API calls
- localStorage

---

## ❓4. What does JSON.parse do?

👉 Converts JSON string → JS object

```js
JSON.parse('{"name":"Dilip"}');
```

💡 Important:

- Throws error if invalid JSON

---

## ❓5. What happens to undefined in JSON?

👉 Behavior differs:

```js
JSON.stringify({ a: undefined }); // '{}'
JSON.stringify([undefined]); // '[null]'
```

💡 WHY:

- Objects → remove
- Arrays → convert to null

---

## ❓6. What happens to functions?

```js
JSON.stringify({
  fn: () => {},
});
```

👉 Output:

```json
{}
```

💡 WHY:

- JSON doesn’t support functions

---

## ❓7. What happens to Date objects?

```js
JSON.stringify({ date: new Date() });
```

👉 Output:

```json
{ "date": "2026-..." }
```

💡 Converted to ISO string

---

## ❓8. What is circular reference error?

```js
const obj = {};
obj.self = obj;

JSON.stringify(obj); ❌
```

👉 Error:

> Converting circular structure to JSON

💡 WHY:

- Infinite recursion

---

## ❓9. How to handle JSON.parse errors?

```js
try {
  JSON.parse(data);
} catch (e) {
  console.error("Invalid JSON");
}
```

💡 Always validate external data

---

## ❓10. What is replacer in JSON.stringify?

👉 Custom function/array to control serialization

```js
JSON.stringify(obj, (key, value) => {
  if (key === "password") return undefined;
  return value;
});
```

💡 Used for:

- Filtering
- Transforming

---

## ❓11. What is reviver in JSON.parse?

👉 Used to transform parsed values

```js
JSON.parse(json, (key, value) => {
  if (key === "date") return new Date(value);
  return value;
});
```

---

## ❓12. Can JSON handle special values (NaN, Infinity)?

```js
JSON.stringify({ value: NaN });
```

👉 Output:

```json
{ "value": null }
```

💡 All become `null`

---

## ❓13. Can JSON be used for deep cloning?

```js
const clone = JSON.parse(JSON.stringify(obj));
```

👉 Works for simple objects

❌ Fails for:

- Functions
- Dates
- Undefined

---

## ❓14. Why JSON requires double quotes?

👉 JSON standard requires:

- Keys → "string"
- Values → "string"

❌ Invalid:

```js
{ name: 'Dilip' } ❌
```

---

## ❓15. What is pretty printing?

```js
JSON.stringify(obj, null, 2);
```

👉 Adds spacing for readability

💡 Used in debugging

---

## ❓16. Why JSON is preferred over XML?

👉 JSON:

- Smaller size
- Faster parsing
- Easier syntax

---

## ❓17. What are JSON limitations?

- No functions
- No undefined
- No circular references
- Limited data types

---

## ❓18. Is JSON secure?

👉 Not inherently

💡 Risks:

- Malicious input
- Injection

👉 Always validate data

---

## ❓19. What is difference between JSON and Object literal?

| Feature   | JSON     | JS Object |
| --------- | -------- | --------- |
| Type      | String   | Object    |
| Quotes    | Required | Optional  |
| Functions | ❌       | ✅        |

---

## ❓20. Where is JSON used in frontend?

- API requests/responses
- localStorage/sessionStorage
- Config files
- Data exchange

---

## 🔄 2. Streaming JSON

- Avoid full memory load

---

- MessagePack → compact

---

## 🧠 4. Data Normalization

- Avoid deeply nested JSON
  👉 Improves performance
