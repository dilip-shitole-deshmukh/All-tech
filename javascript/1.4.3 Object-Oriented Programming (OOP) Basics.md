## 👉 Object-Oriented Programming (OOP) Basics — Deep-Dive

# 🔹 Definition

- **OOP (Object-Oriented Programming)** is a programming paradigm where we organize code using **objects (data + behavior together)**.
- It helps in building **modular, reusable, and maintainable code**.

👉 Simple interview line:
**“OOP is about structuring code using objects that encapsulate data and behavior.”**

---

# 🔹 Core Concepts (4 Pillars of OOP)

---

## 🔸 1. Encapsulation (Data Hiding)

### ✅ Explanation

- Encapsulation means **wrapping data and methods together** inside an object.
- It also allows **restricting direct access** to some data.

👉 WHY:

- Prevents accidental modification → improves security and maintainability.

---

### 💻 Example

```js id="j6a8k2"
class BankAccount {
  #balance = 0; // private field

  deposit(amount) {
    this.#balance += amount;
  }

  getBalance() {
    return this.#balance;
  }
}
```

👉 `#balance` cannot be accessed directly → encapsulation

---

## 🔸 2. Abstraction

### ✅ Explanation

- Abstraction means **hiding complex implementation details** and exposing only necessary functionality.
- Users don’t need to know how something works internally.

👉 Real-life analogy: You drive a car without knowing engine internals.

---

### 💻 Example

```js id="r5k9q3"
class Car {
  start() {
    console.log("Car started");
  }
}
```

👉 User just calls `start()` → doesn’t care about engine logic

---

## 🔸 3. Inheritance

### ✅ Explanation

- Inheritance allows one class/object to **reuse properties and methods of another**.
- Promotes **code reuse and hierarchy**.

---

### 💻 Example

```js id="t8p4m1"
class Animal {
  speak() {
    console.log("Animal sound");
  }
}

class Dog extends Animal {
  speak() {
    console.log("Bark");
  }
}
```

👉 `Dog` inherits from `Animal`

---

## 🔸 4. Polymorphism

### ✅ Explanation

- Same method behaves differently based on context.
- Achieved via method overriding or dynamic behavior.

---

### 💻 Example

```js id="c7v2n9"
class Animal {
  speak() {
    console.log("Sound");
  }
}

class Dog extends Animal {
  speak() {
    console.log("Bark");
  }
}
```

👉 Same method `speak()` → different outputs

# 🔹 How OOP Works in JavaScript (Important)

---

## 🔸 Prototype-Based, Not Classical

### ✅ Explanation

- JavaScript does NOT have classical OOP like Java/C++.
- It uses **prototypes** for inheritance.

👉 Classes are just **syntactic sugar over prototypes**

---

### 💻 Example

```js id="n2b7k4"
function Person(name) {
  this.name = name;
}

Person.prototype.greet = function () {
  console.log(this.name);
};
```

👉 Same behavior as class

# 🔹 Common Mistakes / Traps

---

### ❌ Mistake 1: Thinking JS is class-based

👉 JS is **prototype-based**, classes are just syntax

---

### ❌ Mistake 2: Overusing inheritance

👉 Leads to tight coupling

---

### ❌ Mistake 3: Ignoring encapsulation

👉 Direct state mutation causes bugs

---

# 🔹 When to Use / When NOT to Use

---

### ✅ Use OOP When:

- Complex data models
- Reusable components
- Clear hierarchy needed

---

### ❌ Avoid When:

- Simple logic (use functions instead)
- Over-engineering small features

# 🔹 Interview Q&A

---

### 1. What is OOP?

- Programming paradigm using objects to structure code.
- Combines data and behavior.

---

### 2. What are 4 pillars of OOP?

- Encapsulation, Abstraction, Inheritance, Polymorphism
- Each improves code structure and reuse.

---

### 3. Is JavaScript class-based?

- ❌ No
- It is prototype-based
- Classes are syntactic sugar

---

### 4. What is encapsulation?

- Hiding internal data and exposing controlled access.
- Improves security and maintainability.

---

### 5. What is inheritance?

- Reusing properties/methods from parent class.
- Helps avoid duplication.

---

### 6. What is polymorphism?

- Same method behaves differently.
- Achieved via overriding.

---

### 7. What is abstraction?

- Hiding complexity and exposing simple interface.
- Improves usability.

---

### 8. Difference between class and prototype?

- Class → syntax
- Prototype → actual mechanism
