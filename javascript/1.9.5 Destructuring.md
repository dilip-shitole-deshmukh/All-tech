## 🧠 Destructuring (JavaScript)

---

## 🔹 Definition

Destructuring is a syntax that allows you to **extract values from arrays or properties from objects into variables**.

👉 In simple terms:

> “Unpack values from arrays/objects into separate variables in a clean way”

💡 Helps reduce repetitive code and improves readability.

---

## 🔹 Core Explanation

---

## 🟢 1. Array Destructuring

```js
const arr = [10, 20, 30];

const [a, b, c] = arr;
```

🧠 What happens:

- `a = 10`, `b = 20`, `c = 30`
- Based on **position (index)**

---

### 💡 Skipping Values

```js
const [a, , c] = [1, 2, 3];
```

👉 `a = 1`, `c = 3` (skips index 1)

---

### 💡 Default Values

```js
const [a = 5, b = 10] = [1];
```

👉 `a = 1`, `b = 10` (default used)

---

## 🔵 2. Object Destructuring

```js
const user = { name: "Dilip", age: 25 };

const { name, age } = user;
```

🧠 What happens:

- Extracts based on **property names**
- Order doesn’t matter

---

### 💡 Renaming Variables

```js
const { name: userName } = user;
```

👉 `userName = "Dilip"`

---

### 💡 Default Values

```js
const { city = "Pune" } = user;
```

👉 Used if property doesn’t exist

---

## 🟡 3. Nested Destructuring 🔥

```js
const user = {
  name: "Dilip",
  address: {
    city: "Pune",
  },
};

const {
  address: { city },
} = user;
```

👉 `city = "Pune"`

---

## 🔁 4. Function Parameter Destructuring

```js
function greet({ name, age }) {
  console.log(name, age);
}

greet({ name: "Dilip", age: 25 });
```

🧠 WHY:

- Directly extract needed values
- Cleaner function signature

---

## 🔹 Example(s) with Code

---

### ✅ Example 1: Swap Variables 🔥

```js
let a = 1;
let b = 2;

[a, b] = [b, a];

console.log(a, b); // 2, 1
```

👉 No temp variable needed

---

### ✅ Example 2: API Response

```js
const response = {
  data: { id: 1, name: "Dilip" },
};

const {
  data: { name },
} = response;
```

👉 Extract deeply nested values

---

### ✅ Example 3: Function Defaults

```js
function createUser({ name = "Guest" }) {
  console.log(name);
}

createUser({}); // Guest
```

## 🔹 Common Mistakes / Traps

---

### ❌ Mistake 1: Wrong variable name

```js
const { name } = obj;
```

👉 Must match property name

---

### ❌ Mistake 2: Undefined errors

```js
const { city } = undefined; // ❌ crash
```

👉 Need safe fallback

---

### ❌ Mistake 3: Nested destructuring failure

```js
const {
  address: { city },
} = user;
```

👉 Fails if `address` is undefined

---

### ❌ Mistake 4: Confusing array vs object

```js
const { 0: a } = [1,2]; ❌ confusing
```

## 🔹 Interview Q&A

### ❓1. What is destructuring?

Extracting values from arrays/objects into variables.

---

### ❓2. Difference between array & object destructuring?

- Array → position
- Object → property name

---

### ❓3. Can we set default values?

✅ Yes

---

### ❓4. Can we rename variables?

✅ Yes

---

### ❓5. What is nested destructuring?

Extracting values from nested objects

---

### ❓6. Can destructuring be used in function params?

✅ Yes

---

### ❓7. What happens if property not found?

Returns `undefined` or default

---

### ❓8. Is destructuring shallow or deep?

Shallow extraction

## 🔹 Senior-Level Insights 🚀

---

### ⚡ Safe Destructuring Pattern

```js
const { city } = user || {};
```

👉 Prevents crash

---

### 🧠 Optional Chaining Combo

```js
const city = user?.address?.city;
```

👉 Safer alternative

---

### 🔄 Performance Note

- Destructuring is syntactic sugar
- No major performance difference
