# 🧠 Flatten Complex Objects

---

## 🔹 Definition

👉 **Simple Definition (2–3 lines):**
Flattening a complex object means converting a deeply nested object into a single-level object with compound keys.
Example: `{ a: { b: 1 } } → { "a.b": 1 }`.

👉 **Deeper Explanation (2–3 lines):**
It involves traversing nested objects/arrays and building a **key path string** to represent hierarchy.
Used mainly for **data transformation, APIs, and UI-friendly structures**.

---

# 🔹 Deep Explanation (Core Section)

---

## 1️⃣ Mental Model (Tree Traversal)

- A nested object behaves like a **tree**:
  - Keys → nodes
  - Values → leaf nodes or subtrees

💡 Flattening = **DFS traversal + path building**

Example:

```js
{
  user: {
    address: {
      city: "Pune";
    }
  }
}
```

→ `"user.address.city": "Pune"`

---

## 2️⃣ Key Path Construction

- We build keys using:
  - Dot notation → `"a.b.c"`
  - Bracket notation → `"a[0].b"`

💡 Why important:

- Determines how data is accessed later

⚠️ Edge Case:

- Keys may contain dots → need escaping

---

## 3️⃣ Handling Arrays Inside Objects

```js
{
  users: [{ name: "A" }, { name: "B" }];
}
```

- Arrays require index-based keys:

```js
"users[0].name": "A"
```

💡 Internals:

- Arrays are also objects → iterate with index

⚠️ Edge Case:

- Mixed nesting (object inside array inside object)

---

## 4️⃣ Recursion Strategy (Core Logic)

- For each key:
  - If value is object/array → recurse
  - Else → assign value

💡 Why recursion:

- Unknown depth → dynamic traversal

⚠️ Edge Case:

- `null` is typeof object → must handle separately

---

## 5️⃣ Handling Special Types

- `null` → should be treated as value
- `Date`, `Map`, `Set` → may need custom logic

💡 Example:

```js
typeof null === "object"; // tricky!
```

⚠️ Must check:

```js
value !== null && typeof value === "object";
```

---

## 6️⃣ Circular References (Advanced)

```js
const obj = {};
obj.self = obj;
```

- Causes infinite recursion

💡 Solution:

- Use `WeakSet` to track visited objects

---

## 7️⃣ Performance Considerations

- Time Complexity → O(n) (visit each key once)
- Space Complexity → depends on recursion depth

⚠️ Deep nesting → stack overflow risk

# 🔹 Example(s) with Code

---

## ✅ Example 1: Basic Flatten Object

```js
function flatten(obj, parentKey = "", result = {}) {
  for (let key in obj) {
    const newKey = parentKey ? `${parentKey}.${key}` : key;

    if (obj[key] !== null && typeof obj[key] === "object") {
      flatten(obj[key], newKey, result);
    } else {
      result[newKey] = obj[key];
    }
  }

  return result;
}

const input = { a: { b: { c: 1 } } };
console.log(flatten(input));
```

### 🔍 Execution:

1. Start with root object
2. Build key `"a"` → recurse
3. Build `"a.b"` → recurse
4. Assign `"a.b.c": 1`

💡 Output:

```js
{ "a.b.c": 1 }
```

💡 WHY:

- Recursively builds full path

---

## ⚡ Example 2: Handling Arrays

```js
function flatten(obj, parentKey = "", result = {}) {
  for (let key in obj) {
    const value = obj[key];
    const newKey = parentKey ? `${parentKey}.${key}` : key;

    if (Array.isArray(value)) {
      value.forEach((item, index) => {
        flatten(item, `${newKey}[${index}]`, result);
      });
    } else if (value !== null && typeof value === "object") {
      flatten(value, newKey, result);
    } else {
      result[newKey] = value;
    }
  }

  return result;
}

console.log(flatten({ users: [{ name: "A" }] }));
```

### 🔍 Execution:

1. Detect array
2. Iterate with index
3. Build `"users[0].name"`

💡 Output:

```js
{ "users[0].name": "A" }
```

💡 WHY:

- Array indices included in path

---

## ⚡ Example 3: Circular Reference (Interview-Level)

```js
function flatten(obj, parentKey = "", result = {}, seen = new WeakSet()) {
  if (seen.has(obj)) return result;
  seen.add(obj);

  for (let key in obj) {
    const value = obj[key];
    const newKey = parentKey ? `${parentKey}.${key}` : key;

    if (value !== null && typeof value === "object") {
      flatten(value, newKey, result, seen);
    } else {
      result[newKey] = value;
    }
  }

  return result;
}
```

### 🔍 Execution:

- Tracks visited objects
- Prevents infinite recursion

💡 WHY:

- Circular references break naive recursion

- ✅ Ensure unique path
