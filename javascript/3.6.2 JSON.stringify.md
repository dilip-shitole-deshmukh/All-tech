## 📦 `JSON.stringify()` (JavaScript Deep Dive)

This is a **🟡 Conceptual + Practical Topic** — simple on surface, but interviewers often test **edge cases, replacer, and serialization behavior**.

---

# 🔹 Definition

👉 `JSON.stringify()` converts a JavaScript value (object/array) into a **JSON string**

- Used for **serialization**
- Makes data ready for:
  - Network transfer
  - Storage

💡 Simple interview line:

> “`JSON.stringify()` converts JavaScript objects into JSON string format for storage or transmission.”

---

# 🔹 Core Explanation

---

## 🧠 1. Basic Syntax

```js
JSON.stringify(value, replacer, space);
```

---

### 🔍 Parameters:

1. **value** → object to convert
2. **replacer (optional)** → filter/transform values
3. **space (optional)** → formatting (pretty print)

---

## ⚙️ 2. Basic Example

```js
const user = { name: "Dilip", age: 25 };

const json = JSON.stringify(user);

console.log(json);
// '{"name":"Dilip","age":25}'
```

---

## 🧠 Execution

- Converts object → string
- Keys become strings
- Output is valid JSON

---

# 🔹 Tricky Behavior (VERY IMPORTANT)

---

## ⚠️ 1. Functions are Ignored

```js
const obj = {
  name: "Dilip",
  greet: () => "Hi",
};

JSON.stringify(obj);
```

👉 Output:

```json
{ "name": "Dilip" }
```

💡 WHY:

- JSON doesn’t support functions

---

## ⚠️ 2. Undefined is Removed

```js
JSON.stringify({ a: undefined });
```

👉 Output:

```json
{}
```

---

👉 But inside arrays:

```js
JSON.stringify([undefined]);
```

👉 Output:

```json
[null]
```

💡 Key difference:

- Object → removed
- Array → converted to `null`

---

## ⚠️ 3. NaN / Infinity

```js
JSON.stringify({ value: NaN });
```

👉 Output:

```json
{ "value": null }
```

---

## ⚠️ 4. Date Conversion

```js
JSON.stringify({ date: new Date() });
```

👉 Output:

```json
{ "date": "2026-..." }
```

💡 Date becomes ISO string

---

## ⚠️ 5. Circular Reference (Error)

```js
const obj = {};
obj.self = obj;

JSON.stringify(obj); ❌
```

👉 Throws:

> Converting circular structure to JSON

---

## ⚠️ 6. Symbol is Ignored

```js
JSON.stringify({ key: Symbol("id") });
```

👉 Output:

```json
{}
```

---

# 🔹 Advanced Features

---

## ⚙️ 1. Replacer (Filter Data)

---

### 🔧 Array form

```js
JSON.stringify(user, ["name"]);
```

👉 Only includes selected keys

---

### 🔧 Function form

```js
JSON.stringify(user, (key, value) => {
  if (key === "password") return undefined;
  return value;
});
```

👉 Used to:

- Remove sensitive data
- Transform values

---

## ⚙️ 2. Space (Pretty Print)

```js
JSON.stringify(user, null, 2);
```

👉 Output:

```json
{
  "name": "Dilip",
  "age": 25
}
```

💡 Useful for debugging/logging

---

# 🔹 Example (Full Usage)

```js
const user = {
  name: "Dilip",
  password: "secret",
};

const json = JSON.stringify(
  user,
  (key, value) => {
    if (key === "password") return undefined;
    return value;
  },
  2,
);

console.log(json);
```

---

## 🧠 Output

```json
{
  "name": "Dilip"
}
```

# 🔹 When to Use / NOT Use

---

### ✅ Use when:

- Sending data over network
- Storing objects

---

### ❌ Avoid when:

- Object has circular references
- Need to preserve functions

---

# 🔹 Common Mistakes / Traps

---

## ❌ Expecting functions in JSON

👉 They are removed

---

## ❌ Forgetting stringify in API

```js
fetch("/api", { body: data }); ❌
```

---

## ❌ Not handling circular references

👉 Causes runtime error

---

## ❌ Assuming undefined behaves same everywhere

👉 Object vs array behavior differs

---

# 🔹 Advantages & Pitfalls

---

## ✅ Advantages

- Standard format
- Easy to use
- Cross-platform

---

## ⚠️ Pitfalls

- Limited data types
- No circular references
- Performance cost for large objects

---

# 🔹 Best Practices

✔ Use replacer to filter sensitive data
✔ Use pretty print for debugging only
✔ Validate data before stringify
✔ Avoid large objects if possible
✔ Handle circular structures carefully

---

# 🔹 Senior-Level Insights 🧠

---

## ⚡ 1. Performance Consideration

- `JSON.stringify()` is expensive for large objects
  👉 Optimize:
- Send only required data

---

## 🔄 2. Deep Cloning Trick (BUT LIMITED)

```js
const clone = JSON.parse(JSON.stringify(obj));
```

👉 Works for simple objects

❌ Fails for:

- Functions
- Dates
- Undefined

---

## 🧠 3. Custom Serialization Strategy

- Use replacer for:
  - Security
  - Data transformation

---

## 📊 4. Alternative APIs

- `structuredClone()` → better deep clone
- Libraries (lodash)

# 🔹 Interview Q&A 🎯

---

### 1. What is JSON.stringify?

Method to convert JS object into JSON string.

---

### 2. What are its parameters?

value, replacer, space.

---

### 3. What happens to functions?

They are removed.

---

### 4. What happens to undefined?

Removed in objects, converted to null in arrays.

---

### 5. What happens to Date?

Converted to string.

---

### 6. What is replacer?

Function/array to customize serialization.

---

### 7. What is space parameter?

Used for formatting output.

---

### 8. What is circular reference error?

Object referencing itself cannot be stringified.

---

### 9. Can stringify clone objects?

Yes, but limited.

---

### 10. Why is JSON.stringify used?

For data transfer and storage.
