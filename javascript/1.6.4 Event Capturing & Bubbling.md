## 🧠 Event Capturing & Bubbling (JavaScript)

---

## 🔹 Definition

Event Capturing and Bubbling are **two phases of event propagation in the DOM**.

👉 In simple terms:

> “When an event happens, it travels through the DOM tree in a specific order”

💡 This flow determines **which event handlers run first**.

---

## 🔹 Core Explanation

---

### ⚙️ Event Propagation Phases (Very Important 🔥)

When you click an element, the event goes through **3 phases**:

```text
1. Capturing Phase (Top → Down)
2. Target Phase (Actual Element)
3. Bubbling Phase (Bottom → Up)
```

👉 Example DOM:

```html
<div id="parent">
  <button id="child">Click</button>
</div>
```

---

### 🔵 1. Capturing Phase (Top → Down)

- Event starts from **root (document)**
- Travels **downwards to target element**

```js id="h3mq3v"
parent.addEventListener("click", handler, true);
```

💡 `true` → enables capturing phase

---

### 🟢 2. Target Phase

- Event reaches the **actual element clicked**
- Handlers on target execute

---

### 🔴 3. Bubbling Phase (Bottom → Up)

- Event bubbles **from target back to root**

```js id="a5i4rc"
parent.addEventListener("click", handler); // default = bubbling
```

💡 This is **default behavior**

---

## 🔹 Example(s) with Code

---

### ✅ Example 1: Bubbling (Default Behavior)

```js id="uq3o7s"
document.getElementById("parent").addEventListener("click", () => {
  console.log("Parent clicked");
});

document.getElementById("child").addEventListener("click", () => {
  console.log("Child clicked");
});
```

### 🧠 Output when clicking child:

```text
Child clicked
Parent clicked
```

👉 WHY:

- Event triggers child → then bubbles up to parent

---

### ✅ Example 2: Capturing Phase

```js id="ckefpn"
parent.addEventListener(
  "click",
  () => {
    console.log("Parent (capture)");
  },
  true,
);

child.addEventListener("click", () => {
  console.log("Child");
});
```

### 🧠 Output:

```text
Parent (capture)
Child
```

👉 WHY:

- Capturing runs **before bubbling**

---

### ✅ Example 3: stopPropagation() 🔥

```js id="yrczqo"
child.addEventListener("click", (e) => {
  e.stopPropagation();
  console.log("Child only");
});

parent.addEventListener("click", () => {
  console.log("Parent");
});
```

### 🧠 Output:

```text
Child only
```

👉 WHY:

- Stops event from moving upward

---

### ✅ Example 4: stopImmediatePropagation() ⚠️

```js id="ifvz85"
btn.addEventListener("click", (e) => {
  e.stopImmediatePropagation();
  console.log("First");
});

btn.addEventListener("click", () => {
  console.log("Second");
});
```

👉 Only "First" runs

## 🔹 Real-world Use Cases

---

### 🌐 1. Event Delegation (Very Important)

```js id="qcrf1x"
parent.addEventListener("click", (e) => {
  if (e.target.matches(".child")) {
    console.log("Child clicked");
  }
});
```

👉 Uses bubbling → improves performance

---

### 🧾 2. Preventing Event Propagation

- Stop modal close when clicking inside
- Prevent parent handlers

---

### 🎯 3. Complex UI Interactions

- Nested components
- Dropdowns, modals, menus

---

## 🔹 When to Use / When NOT to Use

---

### ✅ Use Bubbling (Default)

- Event delegation
- Most UI interactions

---

### ✅ Use Capturing

- Rare cases
- When parent must handle event first

---

### ❌ Avoid

- Overusing `stopPropagation` (breaks flow)
- Mixing capturing & bubbling without clarity

---

## 🔹 Common Mistakes / Traps

---

### ❌ Mistake 1: Not understanding order

👉 Developers think parent runs first

👉 Reality:

- Default = bubbling → child first

---

### ❌ Mistake 2: Forgetting third parameter

```js id="y8fhrv"
addEventListener("click", fn); // bubbling
addEventListener("click", fn, true); // capturing
```

---

### ❌ Mistake 3: Overusing stopPropagation

👉 Can break event delegation

---

### ❌ Mistake 4: Confusing `target` vs `currentTarget`

```js id="fgg6h9"
e.target; // actual clicked element
e.currentTarget; // element with listener
```

---

## 🔹 Interview Q&A

---

### ❓1. What is event bubbling?

Event propagates from target → parent → root.

---

### ❓2. What is event capturing?

Event propagates from root → target.

---

### ❓3. Which is default?

👉 Bubbling

---

### ❓4. How to enable capturing?

Pass `true` in `addEventListener`.

---

### ❓5. What is stopPropagation?

Stops event from moving further.

---

### ❓6. Difference between target and currentTarget?

- target → actual element
- currentTarget → listener element

---

### ❓7. What is event delegation?

Using parent to handle child events via bubbling.

---

### ❓8. What is stopImmediatePropagation?

Stops all handlers on same element.

---

## 🔹 Advantages / Pitfalls

---

### ✅ Advantages

- Efficient event handling
- Enables delegation
- Reduces number of listeners

---

### ❌ Pitfalls

- Hard to debug
- Unexpected behavior if misunderstood
- Can break flow if misused

---

## 🔹 Best Practices

---

✔ Use bubbling by default
✔ Use event delegation for lists
✔ Avoid unnecessary stopPropagation
✔ Understand event phases clearly
✔ Use `currentTarget` carefully


| Capturing | Control order       | Rare use case                |
