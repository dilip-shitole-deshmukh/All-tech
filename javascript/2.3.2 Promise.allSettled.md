## 🧠 `Promise.allSettled()` (JavaScript)

> ⚠️ This is a **🟡 Conceptual async topic** → focus on **“wait for all results regardless of success/failure”**

---

## 🔹 Definition

`Promise.allSettled()` takes an **array of promises** and returns a **single promise** that resolves **after all promises are settled** (either fulfilled or rejected).

👉 In simple terms:

> “Give me results of all tasks — I don’t care if they succeed or fail”

💡 Key difference:

- ✔ Never fails early
- ✔ Always returns results for all promises

---

## 🔹 Core Explanation

---

## 🟢 1. How It Works

```js
Promise.allSettled([p1, p2, p3]);
```

🧠 Behavior:

- Runs all promises **in parallel**
- Waits until **all are completed**
- Returns an array of objects describing each result

👉 Each result has:

```js
{
  status: "fulfilled" | "rejected",
  value: ...,   // if fulfilled
  reason: ...   // if rejected
}
```

---

## 🔵 2. Example (Mixed Results)

```js
const p1 = Promise.resolve("Success 1");
const p2 = Promise.reject("Error 2");
const p3 = Promise.resolve("Success 3");

Promise.allSettled([p1, p2, p3]).then((results) => console.log(results));
```

🧠 Output:

```text
[
  { status: "fulfilled", value: "Success 1" },
  { status: "rejected", reason: "Error 2" },
  { status: "fulfilled", value: "Success 3" }
]
```

👉 WHY:

- It doesn’t stop on failure
- Gives full visibility

---

## 🔴 3. Key Behavior (Important 🔥)

👉 Unlike `Promise.all`:

- ❌ No fail-fast
- ✔ Waits for all

👉 Even if all fail:

```js
Promise.allSettled([Promise.reject("A"), Promise.reject("B")]);
```

👉 Still resolves with results array

---

## 🟡 4. Order Guarantee

```js
const p1 = new Promise((res) => setTimeout(() => res("A"), 2000));
const p2 = new Promise((res) => setTimeout(() => res("B"), 1000));

Promise.allSettled([p1, p2]).then(console.log);
```

🧠 Output:

```text
[
  { status: "fulfilled", value: "A" },
  { status: "fulfilled", value: "B" }
]
```

👉 WHY:

- Order is based on input, not completion

## 🔹 Example(s) with Code

---

### ✅ Example 1: API Batch Calls

```js
async function loadData() {
  const results = await Promise.allSettled([
    fetch("/users"),
    fetch("/posts"),
    fetch("/comments"),
  ]);

  results.forEach((res, i) => {
    if (res.status === "fulfilled") {
      console.log("Success:", res.value);
    } else {
      console.log("Error:", res.reason);
    }
  });
}
```

👉 Useful for dashboards

---

### ⚠️ Example 2: Filtering Successful Results

```js
const results = await Promise.allSettled(promises);

const success = results
  .filter((r) => r.status === "fulfilled")
  .map((r) => r.value);
```

👉 Extract only successful values

---

### ⚠️ Example 3: Non-Promise Values

```js
Promise.allSettled([1, Promise.resolve(2), Promise.reject("err")]).then(
  console.log,
);
```

👉 Non-promises → treated as fulfilled

## 🔹 When to Use / When NOT to Use

---

### ✅ Use `Promise.allSettled`

- Need **all results**
- Want **partial success handling**
- Failure should NOT stop execution

---

### ❌ Avoid

- When all must succeed
  👉 Use `Promise.all`

---

## 🔹 Common Mistakes / Traps

---

### ❌ Mistake 1: Expecting rejection

👉 `allSettled` never rejects

---

### ❌ Mistake 2: Forgetting status check

```js
results.map((r) => r.value); // ❌ may break
```

---

### ❌ Mistake 3: Using for dependent tasks

👉 Not suitable

---

### ❌ Mistake 4: Ignoring performance

👉 Still runs all promises
