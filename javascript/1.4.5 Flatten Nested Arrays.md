# 🧠 Flatten Nested Arrays

---

## 🔹 Definition

👉 **Simple Definition (2–3 lines):**
Flattening an array means converting a nested (multi-dimensional) array into a single-level array.
Example: `[1, [2, [3]]] → [1, 2, 3]`.

👉 **Deeper Explanation (2–3 lines):**
Flattening involves recursively or iteratively extracting elements from nested arrays.
JavaScript provides `Array.prototype.flat()`, but interviews often expect **manual implementation**.

---

# 🔹 Deep Explanation (Core Section)

---

## 1️⃣ What is Nested Structure (Mental Model)

- A nested array is like a **tree structure**, not just a list.
- Each element can be:
  - A value (leaf node)
  - Another array (child node)

💡 Why important:

- Flattening = **tree traversal (DFS)** problem

⚠️ Insight:

- Depth can be unknown → requires dynamic handling

---

## 2️⃣ Native Method: `flat()`

```js
[1, [2, [3]]].flat(2);
```

- Takes a depth parameter
- Default depth = 1

💡 Internals:

- Iterates and flattens level-by-level
- Stops when depth limit reached

⚠️ Edge Case:

- `flat(Infinity)` → completely flatten

---

## 3️⃣ Recursive Approach (Most Asked)

- Recursion explores nested arrays deeply
- For each element:
  - If array → recurse
  - Else → push value

💡 Why recursion:

- Naturally fits tree-like structure

⚠️ Edge Case:

- Very deep arrays → stack overflow

---

## 4️⃣ Iterative Approach (Stack-Based)

- Use stack instead of recursion
- Avoids call stack limits

💡 Internals:

- Push elements into stack
- Pop and process

⚠️ Trade-off:

- Slightly more complex logic

---

## 5️⃣ Depth-Controlled Flattening

- Sometimes you don’t want full flatten
- Need to flatten up to specific level

💡 Example:

```js
[1, [2, [3]]], depth=1 → [1, 2, [3]]
```

---

## 6️⃣ Handling Sparse Arrays (Tricky)

```js
const arr = [1, , [3]];
```

- Native `flat()` removes empty slots

💡 Why:

- Sparse arrays have missing indexes

⚠️ Custom implementation must decide behavior

---

## 7️⃣ Performance Considerations

- Recursive → cleaner but stack-heavy
- Iterative → more control, scalable

💡 Time Complexity:

- O(n) → each element visited once

💡 Space Complexity:

- Depends on recursion depth / stack size

# 🔹 Example(s) with Code

---

## ✅ Example 1: Recursive Flatten

```js
function flatten(arr) {
  const result = [];

  for (let item of arr) {
    if (Array.isArray(item)) {
      result.push(...flatten(item));
    } else {
      result.push(item);
    }
  }

  return result;
}

console.log(flatten([1, [2, [3, 4]]]));
```

### 🔍 Execution:

1. Loop over array
2. If element is array → recursive call
3. Spread results into final array

💡 Output:

```js
[1, 2, 3, 4];
```

💡 WHY:

- Recursion keeps diving until primitive value

---

## ⚡ Example 2: Depth-based Flatten

```js
function flattenDepth(arr, depth = 1) {
  const result = [];

  for (let item of arr) {
    if (Array.isArray(item) && depth > 0) {
      result.push(...flattenDepth(item, depth - 1));
    } else {
      result.push(item);
    }
  }

  return result;
}

console.log(flattenDepth([1, [2, [3]]], 1));
```

### 🔍 Execution:

- Only flattens one level

💡 Output:

```js
[1, 2, [3]];
```

💡 WHY:

- Stops recursion when depth = 0

---

## ⚡ Example 3: Iterative (Interview-Level)

```js
function flattenIterative(arr) {
  const stack = [...arr];
  const result = [];

  while (stack.length) {
    const item = stack.pop();

    if (Array.isArray(item)) {
      stack.push(...item);
    } else {
      result.push(item);
    }
  }

  return result.reverse();
}

console.log(flattenIterative([1, [2, [3, 4]]]));
```

### 🔍 Execution:

1. Push elements into stack
2. Pop last element
3. If array → expand
4. Reverse final result

💡 Output:

```js
[1, 2, 3, 4];
```

💡 WHY:

- Stack processes elements LIFO → reverse needed

# 🔹 Common Mistakes / Traps

---

### ❌ Mistake 1: Forgetting recursion base case

- ❌ Infinite recursion
- ✅ Always check `Array.isArray`
- 💡 Prevents crash

---

### ❌ Mistake 2: Mutating original array

- ❌ Changing input
- ✅ Return new array
- 💡 Functional approach safer

---

### ❌ Mistake 3: Not handling depth

- ❌ Always flatten completely
- ✅ Support depth parameter

---

### ❌ Mistake 4: Order issues (iterative)

- ❌ Wrong order output
- ✅ Use reverse()
- 💡 Stack reverses order
