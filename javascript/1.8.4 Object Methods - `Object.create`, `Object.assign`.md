## 🧠 Object Methods: `Object.create` & `Object.assign`

---

## 🔹 Definition

These are built-in methods used to **create objects and copy properties between objects**.

👉 In simple terms:

- `Object.create` → create object with a specific prototype
- `Object.assign` → copy properties from one/more objects to another

💡 They are fundamental for **object composition, inheritance, and cloning**

---

## 🔹 Core Explanation

---

## 🟢 1. `Object.create()`

### ⚙️ Syntax

```js
Object.create(proto, propertiesObject?)
```

---

### 🧠 How it Works

- Creates a **new object**
- Sets its internal `[[Prototype]]` to the given object

👉 This means:

> The new object inherits properties from the prototype

---

### ✅ Example

```js
const animal = {
  speak() {
    console.log("Animal speaks");
  },
};

const dog = Object.create(animal);

dog.speak(); // Animal speaks
```

🧠 WHY:

- `dog` doesn’t have `speak`
- JS looks in prototype → finds it in `animal`

---

### 🔥 Important Behavior

```js
dog.hasOwnProperty("speak"); // false
```

👉 Because it comes from prototype, not own property

---

### 🧩 Adding Own Properties

```js
dog.name = "Tommy";
```

👉 Now:

- `name` → own property
- `speak` → inherited

---

## 🔵 2. `Object.assign()`

### ⚙️ Syntax

```js
Object.assign(target, ...sources);
```

---

### 🧠 How it Works

- Copies **enumerable properties** from source(s) → target
- Returns the **target object**

👉 It performs a **shallow copy**

---

### ✅ Example

```js
const obj1 = { a: 1 };
const obj2 = { b: 2 };

const result = Object.assign({}, obj1, obj2);

console.log(result); // { a: 1, b: 2 }
```

---

### 🔥 Important Behavior

```js
const target = { a: 1 };
Object.assign(target, { a: 2 });

console.log(target); // { a: 2 }
```

👉 Later values overwrite earlier ones

---

### ⚠️ Shallow Copy Issue

```js
const obj = { nested: { x: 1 } };
const copy = Object.assign({}, obj);

copy.nested.x = 2;

console.log(obj.nested.x); // 2 ❌
```

👉 Same reference for nested object

---

## 🔁 Key Differences

| Feature     | Object.create                | Object.assign   |
| ----------- | ---------------------------- | --------------- |
| Purpose     | Create object with prototype | Copy properties |
| Inheritance | Yes                          | No              |
| Copy type   | N/A                          | Shallow copy    |
| Use case    | Prototypal inheritance       | Cloning/merging |

---

## 🔹 Example(s) with Code

---

### ✅ Example 1: Prototypal Inheritance

```js
const person = {
  greet() {
    console.log("Hello");
  },
};

const user = Object.create(person);
user.greet(); // Hello
```

---

### ✅ Example 2: Object Merge

```js
const defaults = { theme: "light" };
const userPrefs = { theme: "dark" };

const settings = Object.assign({}, defaults, userPrefs);

console.log(settings); // { theme: "dark" }
```

---

### ✅ Example 3: Cloning Object

```js
const original = { a: 1 };
const clone = Object.assign({}, original);
```

👉 Shallow clone

## 🔹 When to Use / When NOT to Use

---

### ✅ Use `Object.create`

- When you need inheritance
- Creating prototype chains

---

### ✅ Use `Object.assign`

- Merging objects
- Shallow cloning

---

### ❌ Avoid

- Using assign for deep copy
- Overusing create instead of classes

---

## 🔹 Common Mistakes / Traps

---

### ❌ Mistake 1: Confusing create with copy

👉 `Object.create` does NOT copy properties

---

### ❌ Mistake 2: Assuming deep copy

```js
Object.assign({}, obj); ❌
```

👉 Only shallow copy

---

### ❌ Mistake 3: Mutating target

```js
Object.assign(target, source);
```

👉 Modifies original object

---

### ❌ Mistake 4: Forgetting prototype chain

👉 Properties may come from prototype

---

## 🔹 Interview Q&A

---

### ❓1. What is Object.create?

Creates object with specified prototype.

---

### ❓2. What is Object.assign?

Copies properties from source to target.

---

### ❓3. Does Object.assign do deep copy?

❌ No, shallow copy only

---

### ❓4. What is prototype?

Object from which another object inherits properties

---

### ❓5. Difference between create and assign?

- create → inheritance
- assign → copying

---

### ❓6. Can Object.assign modify target?

✅ Yes

---

### ❓7. How to clone object safely?

Use spread or assign (shallow), or deep copy methods

---

### ❓8. What happens on property conflict?

Last source overrides previous

---

## 🔹 Advantages / Pitfalls

---

### ✅ Advantages

- Simple object composition
- Easy merging
- Supports prototypal inheritance

---

### ❌ Pitfalls

- Shallow copy issues
- Unexpected mutations
- Prototype confusion

---

## 🔹 Best Practices

---

✔ Use spread (`{...obj}`) instead of assign (cleaner)
✔ Use create for inheritance, not copying
✔ Avoid mutating original objects
✔ Use deep copy when needed
✔ Understand prototype chain

---

## 🔹 Senior-Level Insights 🚀

---

### ⚡ Modern Alternative to assign

```js
const obj = { ...obj1, ...obj2 };
```

👉 Cleaner syntax

---

### 🧠 Prototype Optimization

- `Object.create(null)` → no prototype

```js
const obj = Object.create(null);
```

👉 Useful for pure dictionaries

---

### 🔄 Deep Copy Options

```js
structuredClone(obj);
```

👉 Modern deep cloning

---

### ⚖️ Trade-offs

| Method | Pros        | Cons            |
| ------ | ----------- | --------------- |
| create | Inheritance | Not for copying |
| assign | Simple copy | Shallow         |
| spread | Clean       | Still shallow   |
