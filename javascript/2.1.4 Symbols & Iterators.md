## 🧠 Symbols & Iterators (JavaScript)

> ⚠️ This is a **🟡 Conceptual / Intermediate topic** → expect “WHY + HOW” + internal behavior

---

# 🔹 Definition

### 👉 Symbol

A **primitive data type** that creates **unique identifiers** (even if description is same).

```js
const id = Symbol("id");
```

👉 Used for:

- Unique object keys
- Avoiding naming collisions

---

### 👉 Iterator

An **object that defines how to loop over data** using a `next()` method.

```js
{ value: ..., done: ... }
```

👉 Used internally by:

- `for...of`
- spread operator (`...`)
- arrays, strings, maps, etc.

---

# 🔹 Core Explanation

---

## 🟢 1. Symbols → Unique & Hidden Keys 🔥

```js
const s1 = Symbol("key");
const s2 = Symbol("key");

console.log(s1 === s2); // false
```

🧠 WHY:

- Each Symbol is **guaranteed unique**
- Even with same description

---

### 💡 Using Symbols as Object Keys

```js
const id = Symbol("id");

const user = {
  name: "Dilip",
  [id]: 123,
};

console.log(user[id]); // 123
```

👉 WHY:

- Prevents accidental overwriting
- Not accessible via normal loops

---

### ⚠️ Hidden from Iteration

```js
Object.keys(user); // ["name"]
```

👉 Symbol keys are:

- Not enumerable
- Hidden by default

---

## 🔵 2. Global Symbol Registry

```js
const s1 = Symbol.for("key");
const s2 = Symbol.for("key");

console.log(s1 === s2); // true
```

🧠 WHY:

- `Symbol.for()` uses **shared registry**
- Reuses same symbol

---

## 🟡 3. Iterators → How Looping Works Internally 🔥

### 👉 Iterator Protocol

An object is iterable if it has:

```js
obj[Symbol.iterator]();
```

👉 This returns an iterator

---

### 👉 Iterator Structure

```js
{
  value: any,
  done: boolean
}
```

---

### ✅ Example: Manual Iterator

```js
const arr = [1, 2];

const iterator = arr[Symbol.iterator]();

console.log(iterator.next()); // { value: 1, done: false }
console.log(iterator.next()); // { value: 2, done: false }
console.log(iterator.next()); // { value: undefined, done: true }
```

🧠 WHY:

- `for...of` uses this internally

---

## 🔁 4. Custom Iterator (Important 🔥)

```js
const obj = {
  data: [1, 2, 3],
  [Symbol.iterator]() {
    let index = 0;
    return {
      next: () => ({
        value: this.data[index++],
        done: index > this.data.length,
      }),
    };
  },
};

for (let val of obj) {
  console.log(val);
}
```

👉 Output:

```text
1
2
3
```

## 🔹 Example(s) with Code

---

### ✅ Example 1: Spread uses Iterator

```js
const arr = [1, 2, 3];

console.log([...arr]); // [1,2,3]
```

👉 WHY:

- Spread internally calls iterator

---

### ✅ Example 2: String Iteration

```js
for (let char of "JS") {
  console.log(char);
}
```

👉 Works because string has iterator

---

### ⚠️ Example 3: Non-Iterable Error

```js
const obj = { a: 1 };

[...obj]; // ❌ TypeError
```

👉 No `Symbol.iterator`

- Avoid key conflicts

- Custom looping behavior
- Custom data structures

---

### ❌ Avoid

- Overusing Symbols unnecessarily
- Writing custom iterators when not needed
