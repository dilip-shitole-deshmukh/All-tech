## 🧠 Asynchronous Programming (JavaScript)

> ⚠️ This is a **🟡 Conceptual + Core JS topic** → very important for interviews
> 👉 Focus on **WHY async exists + Event Loop + execution flow**

---

## 🔹 Definition

**Asynchronous programming** allows JavaScript to **execute tasks without blocking the main thread**, enabling other operations to run while waiting for long tasks.

👉 In simple terms:

> “Don’t wait — continue execution and handle result later”

💡 Example:

- API calls
- File loading
- Timers

---

## 🔹 Core Explanation

---

## 🟢 1. Why Async Programming Exists

👉 JavaScript is:

- Single-threaded
- Executes one task at a time

❌ Problem:

- Long tasks block everything

```js
// Blocking example
const data = fetchData(); // takes 5 sec
console.log(data); // UI freezes ❌
```

✅ Solution:

- Use async → non-blocking execution

---

## 🔵 2. Synchronous vs Asynchronous

---

### 🔹 Synchronous (Blocking)

```js
console.log("A");
console.log("B");
console.log("C");
```

🧠 Output:

```text
A B C
```

👉 Executes line by line

---

### 🔹 Asynchronous (Non-blocking)

```js
console.log("A");

setTimeout(() => {
  console.log("B");
}, 0);

console.log("C");
```

🧠 Output:

```text
A C B
```

👉 WHY:

- `setTimeout` is async → delayed execution

---

## 🟡 3. How Async Works (Event Loop 🔥)

👉 JavaScript uses:

```text
Call Stack → Web APIs → Callback Queue → Event Loop
```

### 🧠 Flow:

1. Code enters **Call Stack**
2. Async tasks go to **Web APIs**
3. Callback added to **Queue**
4. **Event Loop** pushes it back when stack is empty

💡 This is the heart of async JS

---

## 🔥 4. Microtask vs Macrotask Queue

---

### 🔹 Microtasks (High Priority)

- Promises (`.then`, `await`)

### 🔹 Macrotasks

- `setTimeout`, `setInterval`

```js
console.log("Start");

setTimeout(() => console.log("Timeout"), 0);

Promise.resolve().then(() => console.log("Promise"));

console.log("End");
```

🧠 Output:

```text
Start
End
Promise
Timeout
```

👉 WHY:

- Microtasks execute before macrotasks

## 🔹 Example(s) with Code

---

### ✅ Example 1: Callback

```js
setTimeout(() => {
  console.log("Async task done");
}, 1000);
```

---

### ✅ Example 2: Promise

```js
fetch("/api")
  .then((res) => res.json())
  .then((data) => console.log(data));
```

---

### ✅ Example 3: Async/Await

```js
async function getData() {
  const res = await fetch("/api");
  const data = await res.json();
  console.log(data);
}
```

## 🔹 Common Mistakes / Traps

---

### ❌ Mistake 1: Thinking JS is multi-threaded

👉 JS is single-threaded (browser provides async APIs)

---

### ❌ Mistake 2: Misunderstanding order

👉 Async code doesn’t run immediately

---

### ❌ Mistake 3: Ignoring event loop

👉 Leads to wrong output expectations

---

### ❌ Mistake 4: Sequential async calls

```js
await a();
await b(); // ❌ slow
```

---

### ❌ Mistake 5: Not handling errors

👉 Causes crashes
