## 🧠 ES6+ Features (Modern JavaScript)

> ⚠️ This is a **🟡 Conceptual / Broad topic** → focus on **WHAT + WHY + WHEN to use**, not deep internals of each

---

## 🔹 Definition

ES6 (ECMAScript 2015) and beyond introduced modern JavaScript features that make code:

- ✅ More readable
- ✅ More maintainable
- ✅ More powerful

👉 In simple terms:

> “ES6+ is the foundation of modern JavaScript development”

---

## 🔹 Core Explanation (Important Features)

---

## 🟢 1. `let` & `const` (Block Scoped Variables)

```js
let a = 10;
const b = 20;
```

🧠 WHY:

- Fix issues with `var` (global leaks, hoisting confusion)
- Block scope → safer variables

👉 `const` → default choice
👉 `let` → when reassignment needed

---

## 🔵 2. Arrow Functions (`=>`)

```js
const sum = (a, b) => a + b;
```

🧠 WHY:

- Short syntax
- No own `this` → uses lexical `this`

⚠️ Edge Case:

- Not suitable for object methods

---

## 🟡 3. Template Literals (```)

```js
const name = "Dilip";
console.log(`Hello ${name}`);
```

🧠 WHY:

- Cleaner string interpolation
- Supports multi-line strings

---

## 🔁 4. Destructuring

```js
const { name } = user;
const [a, b] = arr;
```

🧠 WHY:

- Extract values easily
- Reduces repetitive code

---

## 🔥 5. Spread & Rest (`...`)

```js
const newArr = [...arr];
function fn(...args) {}
```

🧠 WHY:

- Spread → expand
- Rest → collect

👉 Enables immutability patterns

---

## 🧠 6. Default Parameters

```js
function greet(name = "Guest") {
  console.log(name);
}
```

🧠 WHY:

- Avoid manual checks
- Cleaner function definitions

---

## ⚡ 7. Classes (Syntactic Sugar)

```js
class Person {
  constructor(name) {
    this.name = name;
  }
}
```

🧠 WHY:

- Cleaner OOP syntax
- Based on prototypes internally

---

## 🔄 8. Modules (`import/export`)

```js
export const a = 10;
import { a } from "./file";
```

🧠 WHY:

- Code modularization
- Better maintainability

---

## 🌐 9. Promises

```js
fetch(url)
  .then((res) => res.json())
  .catch((err) => console.log(err));
```

🧠 WHY:

- Handle async operations
- Avoid callback hell

---

## 🚀 10. Async / Await

```js
const data = await fetchData();
```

🧠 WHY:

- Cleaner async code
- Looks synchronous

---

## 🔐 11. Optional Chaining & Nullish Coalescing

```js
user?.name ?? "Guest";
```

🧠 WHY:

- Prevent runtime errors
- Correct default values

---

## 🔑 12. Symbols

```js
const id = Symbol("id");
```

🧠 WHY:

- Unique object keys
- Avoid collisions

---

## 🔁 13. Iterators & Generators

```js
function* gen() {
  yield 1;
}
```

🧠 WHY:

- Control iteration
- Lazy execution

---

## 🔹 Example(s) with Code

---

### ✅ Example: Combining ES6 Features

```js
const users = [
  { name: "A", age: 20 },
  { name: "B", age: 30 },
];

const result = users
  .filter((u) => u.age > 25)
  .map(({ name }) => `User: ${name}`);

console.log(result);
```

👉 Uses:

- arrow functions
- destructuring
- template literals
- array methods

## 🔹 Senior-Level Insights 🚀

---

### ⚡ Performance

- Most ES6 features are syntactic sugar
- Minimal performance difference

### 🧠 Readability vs Cleverness

❌ Bad:

```js

```

👉 Hard to debug

✅ Better:

- Break into steps
