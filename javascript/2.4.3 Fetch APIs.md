## 🌐 Fetch API (JavaScript)

> ⚠️ This is a **🟡 Conceptual + Practical core frontend topic**
> 👉 Very common in interviews → tests **async handling + HTTP understanding**

---

## 🔹 Definition

👉 The **Fetch API** is a modern JavaScript API used to **make HTTP requests (GET, POST, etc.) to servers**.

💡 In simple terms:

> “Fetch data from server and work with it asynchronously using promises”

---

## 🔹 Core Explanation

---

## 🟢 1. Basic Syntax

```js
fetch(url, options);
```

👉 Returns a **Promise** that resolves to a **Response object**

---

### ✅ Simple Example (GET request)

```js
fetch("https://api.example.com/data")
  .then((res) => res.json())
  .then((data) => console.log(data))
  .catch((err) => console.error(err));
```

### 🧠 Flow:

1. Fetch sends request
2. Server responds
3. `.json()` parses body
4. Data is used

---

## 🟡 2. Fetch is Promise-based

👉 Unlike old `XMLHttpRequest`, fetch:

- Uses promises
- Works well with async/await
- Cleaner syntax

---

### ✅ Async/Await Version

```js
async function getData() {
  try {
    const res = await fetch("/api/data");
    const data = await res.json();
    console.log(data);
  } catch (err) {
    console.error(err);
  }
}
```

---

## 🔥 3. Important Behavior (Interview Critical)

---

### ❗ Fetch DOES NOT reject on HTTP errors

```js
const res = await fetch("/not-found");
console.log(res.ok); // false
```

👉 Even for 404/500 → promise resolves

💡 You must manually check:

```js
if (!res.ok) {
  throw new Error("HTTP error");
}
```

---

## 🔵 4. Request Options

---

### ✅ POST Request Example

```js
fetch("/api/user", {
  method: "POST",
  headers: {
    "Content-Type": "application/json",
  },
  body: JSON.stringify({ name: "Dilip" }),
});
```

---

### 🔹 Common Options

| Option      | Purpose                |
| ----------- | ---------------------- |
| method      | GET, POST, PUT, DELETE |
| headers     | Metadata               |
| body        | Request data           |
| credentials | Cookies/auth           |
| signal      | AbortController        |

---

## 🔥 5. Response Object

---

```js
const res = await fetch("/api");
```

### Important properties:

| Property   | Meaning        |
| ---------- | -------------- |
| res.ok     | Success status |
| res.status | HTTP status    |
| res.json() | Parse JSON     |
| res.text() | Parse text     |

---

## ⚠️ Tricky Concept: Body is Stream

👉 You can read response body **only once**

```js
const res = await fetch("/api");

await res.json(); // ✅
await res.json(); // ❌ error
```

## 🔹 Example(s) with Code

---

### ✅ Example 1: GET with error handling

```js
async function fetchData() {
  try {
    const res = await fetch("/api");

    if (!res.ok) throw new Error("Failed");

    const data = await res.json();
    console.log(data);
  } catch (err) {
    console.error(err);
  }
}
```

---

### ✅ Example 2: Parallel fetch

```js
const [users, posts] = await Promise.all([
  fetch("/users").then((res) => res.json()),
  fetch("/posts").then((res) => res.json()),
]);
```

---

### ✅ Example 3: Cancel request

```js
const controller = new AbortController();

fetch("/api", { signal: controller.signal });

controller.abort(); // cancel request
```

## 🔹 When to Use / When NOT to Use

---

### ✅ Use Fetch

- Modern apps
- Simple HTTP requests

---

### ❌ Avoid Fetch (sometimes)

- Complex interceptors → use Axios
- Need request cancellation + retry logic built-in

---

## 🔹 Common Mistakes / Traps

---

### ❌ Mistake 1: Assuming fetch throws on 404

👉 It doesn’t → check `res.ok`

---

### ❌ Mistake 2: Not parsing response

```js
fetch("/api").then((res) => console.log(res)); // ❌ raw response
```

---

### ❌ Mistake 3: Forgetting `await`

👉 Leads to unresolved promises

---

### ❌ Mistake 4: Reading body twice

👉 Streams can be consumed once

## 🔹 Senior-Level Insights 🚀

---

### ⚡ Performance Optimization

👉 Avoid sequential fetch:

```js
await fetchA();
await fetchB(); // ❌ slow
```

👉 Use:

```js
await Promise.all([fetchA(), fetchB()]);
```

---

### 🧠 Retry + Timeout Pattern

```js
Promise.race([
  fetch("/api"),
  new Promise((_, reject) => setTimeout(() => reject("Timeout"), 5000)),
]);
```

---

### ⚖️ Fetch vs Axios

| Feature        | Fetch  | Axios  |
| -------------- | ------ | ------ |
| Built-in       | ✅     | ❌     |
| Auto JSON      | ❌     | ✅     |
| Interceptors   | ❌     | ✅     |
| Error handling | Manual | Better |
