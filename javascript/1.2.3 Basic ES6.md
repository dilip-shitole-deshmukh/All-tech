## 👉 Basic ES6 Q&A (Interview Deep-Dive)

# 🔹 1. What is ES6?

### ✅ Definition

- **ES6 (ECMAScript 2015)** is a major update to JavaScript that introduced modern features to make code **cleaner, shorter, and more maintainable**.
- It solves many problems of older JavaScript like variable scoping issues, verbose syntax, and lack of modularity.

---

# 🔹 2. What are `let`, `const`, and `var`?

### ✅ Core Explanation

- `var` is **function-scoped**, while `let` and `const` are **block-scoped** → safer and predictable.
- `let` allows reassignment, `const` does not → but objects inside `const` can still be mutated.
- `var` gets hoisted and initialized as `undefined`, while `let/const` stay in **Temporal Dead Zone (TDZ)**.

### 💻 Example

```js
{
  var a = 10;
  let b = 20;
}
console.log(a); // 10
console.log(b); // ❌ ReferenceError
```

👉 `b` is block-scoped → not accessible outside.

---

# 🔹 3. What are Arrow Functions?

### ✅ Core Explanation

- Short syntax for functions → removes boilerplate (`function`, `return`).
- Arrow functions **do NOT have their own `this`** → they inherit from surrounding scope (lexical `this`).
- Cannot be used as constructors and don’t have `arguments` object.

### 💻 Example

```js
const add = (a, b) => a + b;
```

### ⚠️ Tricky Case

```js
const obj = {
  value: 10,
  get: () => this.value,
};
console.log(obj.get()); // undefined
```

👉 Arrow function uses outer `this` → not `obj`.

# 🔹 4. What is Template Literal?

### ✅ Core Explanation

- Uses backticks (`` ` ``) to create strings.
- Supports **string interpolation** and **multi-line strings**.
- Cleaner alternative to concatenation.

### 💻 Example

```js
const name = "Dilip";
console.log(`Hello ${name}`);
```

---

# 🔹 5. What is Destructuring?

### ✅ Core Explanation

- Allows extracting values from arrays/objects into variables.
- Reduces repetitive code and improves readability.

### 💻 Example

```js
const user = { name: "Dilip", age: 25 };
const { name, age } = user;
```

---

# 🔹 6. What is Spread Operator (`...`)?

### ✅ Core Explanation

- Expands elements of array/object.
- Useful for cloning, merging, or passing values.

### 💻 Example

```js
const arr1 = [1, 2];
const arr2 = [...arr1, 3]; // [1,2,3]
```

---

# 🔹 7. What is Rest Operator?

### ✅ Core Explanation

- Collects multiple values into a single array.
- Used in function parameters.

### 💻 Example

```js
function sum(...nums) {
  return nums.reduce((a, b) => a + b);
}
```

---

# 🔹 8. What are Default Parameters?

### ✅ Core Explanation

- Allows setting default values for function parameters.
- Avoids `undefined` issues.

### 💻 Example

```js
function greet(name = "Guest") {
  return `Hello ${name}`;
}
```

---

# 🔹 9. What are Classes in ES6?

### ✅ Core Explanation

- Syntactic sugar over JavaScript prototypes.
- Makes OOP style easier and cleaner.

### 💻 Example

```js
class Person {
  constructor(name) {
    this.name = name;
  }
}
```

---

# 🔹 10. What are Modules (`import/export`)?

### ✅ Core Explanation

- ES6 introduced native module system.
- Helps split code into reusable files.

### 💻 Example

```js
// file1.js
export const name = "Dilip";

// file2.js
import { name } from "./file1.js";
```

# 🔹 Real-world Use Cases

- 🔹 React uses ES6 heavily (arrow functions, destructuring, modules)
- 🔹 API handling → spread operator for merging responses
- 🔹 Clean UI logic → template literals for dynamic strings
- 🔹 State management → immutability using spread

# 🔹 Common Mistakes / Traps

### ❌ Mistake 1: Thinking `const` makes object immutable

```js
const obj = { a: 1 };
obj.a = 2; // ✅ allowed
```

👉 Only reference is constant, not internal values.

---

### ❌ Mistake 2: Using arrow function for methods

👉 Leads to wrong `this` binding.

---

### ❌ Mistake 3: Confusing spread vs rest

- Spread → expands
- Rest → collects

# 🔹 Interview Q&A

### 1. What is ES6?

- ES6 is a modern JavaScript version introducing features like arrow functions, classes, and modules.
- It improves readability, maintainability, and developer productivity.

---

### 2. Difference between `let` and `const`?

- `let` allows reassignment, `const` does not.
- Both are block-scoped and avoid issues caused by `var`.

---

### 3. Why arrow functions are preferred?

- Shorter syntax and lexical `this`.
- Helps avoid manual binding in callbacks (especially in React).

---

### 4. What is destructuring?

- Extract values from objects/arrays into variables.
- Makes code concise and readable.

---

### 5. Spread vs Rest?

- Spread expands elements.
- Rest collects multiple elements into one variable.

---

### 6. What is template literal?

- String syntax using backticks with interpolation.
- Easier than concatenation.

---

### 7. Can arrow functions be used as constructors?

- ❌ No, because they don’t have `this` binding or `prototype`.

---

### 8. What problem do modules solve?

- Avoid global scope pollution and improve code organization.
- Helps in large-scale applications.

---

# 🔹 Advantages of ES6

- ✔ Cleaner syntax
- ✔ Better scoping (`let`, `const`)
- ✔ Modular code structure
- ✔ Improved readability

---

# 🔹 Best Practices

- ✅ Prefer `const` by default, use `let` only when needed
- ✅ Avoid `var` in modern code
- ✅ Use destructuring for cleaner code
- ✅ Use arrow functions for callbacks, not for object methods
- ✅ Use modules to organize code
