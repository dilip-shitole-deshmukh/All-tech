# 🚀 Basic ES6 (ECMAScript 2015) – Deep Dive Interview Guide

---

# 🔹 Definition

**ES6 (ECMAScript 2015)** is a major update to JavaScript that introduced modern syntax and powerful features to make code:

- ✅ More readable
- ✅ More maintainable
- ✅ More modular
- ✅ More predictable
- ✅ Better for large-scale applications

It transformed JavaScript from a “scripting language” to a **serious enterprise-grade language**.

---

# 🔹 Deep Explanation (Everything You Must Know)

Below are the **core ES6 concepts** you must master for senior interviews.

---

# 1️⃣ `let` & `const`

## 🔹 What Problem Did ES6 Solve?

Before ES6 → only `var`

Problems with `var`:

- ❌ Function-scoped
- ❌ Hoisting confusion
- ❌ Can be redeclared
- ❌ Leads to bugs in loops

---

## 🔹 `let`

- Block-scoped
- Cannot redeclare in same scope
- Can reassign
- Temporal Dead Zone (TDZ)

```js
{
  let count = 10;
  console.log(count);
}
```

---

## 🔹 `const`

- Block-scoped
- Cannot reassign
- Must initialize at declaration
- Object properties CAN change

```js
const user = { name: "Dilip" };
user.name = "Rahul"; // ✅ Allowed
```

⚠️ `const` prevents reassignment, not mutation.

---

# 2️⃣ Arrow Functions (`=>`)

- Short syntax
- Lexical `this`
- No `arguments`
- Cannot be constructor

```js
const add = (a, b) => a + b;
```

Used heavily in:

- React
- Array methods
- Callbacks

---

# 3️⃣ Template Literals (` `)

Before ES6:

```js
"Hello " + name;
```

ES6:

```js
`Hello ${name}`;
```

Supports:

- Multi-line strings
- Expression interpolation
- Tagged templates

---

# 4️⃣ Destructuring

Extract values easily from objects/arrays.

### Object destructuring

```js
const user = { name: "Dilip", age: 30 };
const { name, age } = user;
```

### Array destructuring

```js
const [first, second] = [10, 20];
```

---

# 5️⃣ Default Parameters

```js
function greet(name = "Guest") {
  return `Hello ${name}`;
}
```

Prevents undefined errors.

---

# 6️⃣ Rest & Spread (`...`)

## 🔹 Rest (collect)

```js
function sum(...nums) {
  return nums.reduce((a, b) => a + b);
}
```

## 🔹 Spread (expand)

```js
const arr2 = [...arr1];
```

Used for:

- Copying arrays
- Merging objects
- Immutable updates (React)

---

# 7️⃣ Modules (`import/export`)

Before ES6 → Global pollution.

ES6:

```js
// utils.js
export const add = (a, b) => a + b;

// app.js
import { add } from "./utils.js";
```

Promotes:

- Modular architecture
- Tree shaking
- Maintainability

---

# 8️⃣ Classes

Syntactic sugar over prototypes.

```js
class Person {
  constructor(name) {
    this.name = name;
  }

  greet() {
    return `Hello ${this.name}`;
  }
}
```

Still prototype-based internally.

---

# 9️⃣ Promises

Replaced callback hell.

```js
fetch("/api")
  .then((res) => res.json())
  .then((data) => console.log(data))
  .catch((err) => console.error(err));
```

Foundation for async/await.

---

# 🔟 Symbol

Creates unique identifiers.

```js
const id = Symbol("id");
```

Used in:

- Libraries
- Internal object keys
- Avoiding collisions

---

# 🔹 Real-World Use Cases

---

### 🏢 React Development

- Arrow functions → event handlers
- Spread → state updates
- Destructuring → props
- Modules → component structure

```js
const UserCard = ({ name, age }) => {
  return (
    <div>
      {name} - {age}
    </div>
  );
};
```

---

### 🏦 Payment App Example (Your domain)

```js
const processPayment = async (amount = 0) => {
  try {
    const response = await fetch(`/api/pay?amount=${amount}`);
    return await response.json();
  } catch (err) {
    console.error(err);
  }
};
```

# 🔹 When to Use? Why? Where? How?

| Feature       | When              | Why                             |
| ------------- | ----------------- | ------------------------------- |
| let           | Mutable variable  | Block scope safety              |
| const         | Default choice    | Prevent accidental reassignment |
| Arrow         | Callbacks         | Lexical this                    |
| Spread        | Immutable updates | React performance               |
| Destructuring | Cleaner code      | Reduce verbosity                |
| Modules       | Large apps        | Scalability                     |

# 🔹 10+ Interview Q&A

---

### 1️⃣ Difference between `let` and `var`?

`let` is block-scoped, `var` is function-scoped.

---

### 2️⃣ What is Temporal Dead Zone?

Accessing `let`/`const` before declaration throws error.

---

### 3️⃣ Can `const` object change?

Yes, properties can mutate.

---

### 4️⃣ Difference between rest and spread?

Rest → collects
Spread → expands

---

### 5️⃣ What is tree shaking?

Removing unused exports during build.

---

### 6️⃣ Are ES6 classes truly OOP?

No, syntactic sugar over prototypes.

---

### 7️⃣ How does arrow function handle `this`?

Lexically binds `this` from parent scope.

---

### 8️⃣ What is default export vs named export?

```js
export default App;
export const add = () => {};
```

---

### 9️⃣ What is Promise chaining?

Sequential `.then()` execution.

---

### 🔟 Why prefer `const` by default?

Prevents accidental reassignment.

---

### 1️⃣1️⃣ What is shallow copy via spread?

Copies first level only.

---

### 1️⃣2️⃣ Is ES6 backward compatible?

Needs transpilation (Babel) for older browsers.

# ✅ Advantages

- Cleaner syntax
- Improved readability
- Better async handling
- Modular architecture
- Functional programming support
- Safer variable scoping

---

# ⚡ Pitfalls

---

### ❌ Spread is shallow

```js
const obj2 = { ...obj1 }; // nested objects shared
```

---

### ❌ Arrow functions in object methods

Wrong `this`.

---

### ❌ Over-destructuring

Hurts readability in large objects.

---

### ❌ Misunderstanding `const`

It doesn’t freeze objects.

---

### ❌ Mixing CommonJS & ES Modules improperly

Can break builds.

---

# 🔥 Senior-Level Perspective / Best Practices

---

## 🧠 1. Default to `const`

Only use `let` when reassignment required.

---

## 🧠 2. Use Immutable Patterns

Especially in React.

```js
setState((prev) => ({ ...prev, name: "Dilip" }));
```

---

## 🧠 3. Use Destructuring in Parameters

```js
function createUser({ name, email }) {}
```

Cleaner APIs.

---

## 🧠 4. Avoid Deep Nested Arrow Functions

Impacts readability.

---

## 🧠 5. Understand Underlying Prototypes

Senior engineers know ES6 is sugar over prototypes.

---

## 🧠 6. Use Modules Properly

- Named exports preferred
- Avoid default export in large teams
