# 🔹 Definition

- Replace manual loops and hacks

# 🔥 1️⃣ Array Methods (Very Important)

---

# 🔹 `Array.from()`

### 📌 Definition

Creates a new array from:

- Array-like objects
- Iterable objects (Set, Map, string)

### Example

```js
const str = "Dilip";
const arr = Array.from(str);
console.log(arr);
// ["D", "i", "l", "i", "p"]
```

### Real-world

Convert NodeList to array:

```js
const divs = Array.from(document.querySelectorAll("div"));
```

---

# 🔹 `Array.of()`

### 📌 Definition

Creates array from arguments.

```js
Array.of(5); // [5]
new Array(5); // [empty × 5]
```

⚠️ Important interview difference.

---

# 🔹 `find()`

Returns first matching element.

```js
const users = [{ id: 1 }, { id: 2 }];

const user = users.find((u) => u.id === 2);
```

---

# 🔹 `findIndex()`

Returns index.

```js
users.findIndex((u) => u.id === 2);
```

---

# 🔹 `includes()`

Checks existence.

```js
[1, 2, 3].includes(2); // true
```

Better than `indexOf()`.

---

# 🔥 2️⃣ Object Methods

---

# 🔹 `Object.assign()`

### 📌 Definition

Copies properties from source to target.

```js
const obj1 = { a: 1 };
const obj2 = { b: 2 };

const merged = Object.assign({}, obj1, obj2);
```

⚠️ Shallow copy only.

---

# 🔹 `Object.values()`

```js
Object.values({ a: 1, b: 2 });
// [1,2]
```

---

# 🔹 `Object.entries()`

```js
Object.entries({ a: 1 });
// [["a",1]]
```

Used in iteration.

---

# 🔹 `Object.keys()` (Enhanced usage)

Used with ES6 loops.

```js
for (const key of Object.keys(obj)) {
}
```

# 🔟 10+ Interview Q&A

---

### 1️⃣ Difference between `find()` and `filter()`?

- `find()` → first match
- `filter()` → all matches

---

### 2️⃣ Difference between `includes()` and `indexOf()`?

`includes()` returns boolean directly.

---

### 3️⃣ Is `Object.assign()` deep copy?

No. Shallow copy.

---

### 4️⃣ Why use `Number.isNaN()`?

Safer than global `isNaN()`.

---

### 5️⃣ What does `Array.from()` solve?

Converts array-like to real array.

---

### 6️⃣ What is iterable?

Object implementing `Symbol.iterator`.

---

### 7️⃣ Can `includes()` detect NaN?

Yes.

```js
[NaN].includes(NaN); // true
```

---

### 8️⃣ Difference between `Object.entries()` and `Object.keys()`?

Entries returns key-value pairs.

---

### 9️⃣ When to use `Array.of()`?

When creating array from single numeric value.

---

### 🔟 Performance difference between `find()` and loop?

Similar. But `find()` is cleaner and stops early.

---

### 1️⃣1️⃣ Why prefer ES6 methods over manual loops?

Cleaner, declarative, less error-prone.

# ⚡ Pitfalls

---

### ❌ Shallow Copy Issues

```js
const a = { nested: { x: 1 } };
const b = Object.assign({}, a);
b.nested.x = 5; // affects original
```

---

### ❌ Misusing `find()` for multiple values

Use `filter()` instead.

---

### ❌ Confusing `Array.of()` with `new Array()`

Major interview trap.

---

### ❌ Not handling undefined return from `find()`

```js
users.find((u) => u.id === 100).name; // error
```

---

# 🔥 Senior-Level Perspective / Best Practices

---

## 🧠 1. Prefer Declarative Style

```js
users.find((u) => u.active);
```

Instead of manual loop.

---

## 🧠 2. Use Spread Over `Object.assign()`

Cleaner syntax:

```js
const merged = { ...obj1, ...obj2 };
```

---

## 🧠 3. Always Handle Undefined

```js
const user = users.find(...);
if (!user) return;
```

---

## 🧠 4. Understand Performance

For very large datasets:

- `find()` stops early
- `filter()` loops entire array

---

## 🧠 5. Combine with ES6 Features

```js
const { name } = users.find((u) => u.id === 1) ?? {};
```
