## 🧠 `Promise.any()` (JavaScript)

> ⚠️ This is a **🟡 Conceptual async topic** → focus on **“first successful result wins” + difference from `race`**

---

## 🔹 Definition

`Promise.any()` takes an **array of promises** and returns a **single promise** that resolves as soon as **any one promise fulfills (success)**.

👉 In simple terms:

> “Give me the first successful result, ignore failures”

💡 Key idea:

- ✔ Ignores rejected promises
- ❌ Fails only if **all promises fail**

---

## 🔹 Core Explanation

---

## 🟢 1. How It Works

```js id="c4r9y6"
Promise.any([promise1, promise2, promise3]);
```

🧠 Behavior:

- Runs all promises **in parallel**
- Resolves with **first fulfilled value**
- Ignores rejected ones
- Rejects only when **all promises reject**

---

## 🔵 2. Success Case

```js id="z6rqst"
const p1 = Promise.reject("Error 1");
const p2 = Promise.resolve("Success");
const p3 = Promise.reject("Error 2");

Promise.any([p1, p2, p3]).then(console.log).catch(console.log);
```

🧠 Output:

```text id="xx4v7z"
Success
```

👉 WHY:

- `p2` is first successful promise
- Errors from others are ignored

---

## 🔴 3. All Fail Case (Important 🔥)

```js id="i4t3v2"
const p1 = Promise.reject("Error 1");
const p2 = Promise.reject("Error 2");

Promise.any([p1, p2])
  .then(console.log)
  .catch((err) => console.log(err));
```

🧠 Output:

```text id="j8c1xs"
AggregateError: All promises were rejected
```

👉 WHY:

- No promise succeeded
- Throws **AggregateError** (contains all errors)

---

## 🟡 4. Difference from `Promise.race` (Critical 🔥)

| Feature        | `Promise.race`    | `Promise.any`    |
| -------------- | ----------------- | ---------------- |
| Returns        | First settled     | First fulfilled  |
| Handles reject | Fails immediately | Ignores rejects  |
| Use case       | Timeout           | Fallback success |

💡 Key:

> race = first (success OR failure)
> any = first success only

---

## 🔹 Example(s) with Code

---

### ✅ Example 1: Multiple APIs (Fallback)

```js id="g0q8qk"
Promise.any([fetch("api1"), fetch("api2"), fetch("api3")])
  .then((res) => console.log("Got response"))
  .catch((err) => console.log("All failed"));
```

👉 Returns first working API

---

### ⚠️ Example 2: Slow + Fast + Fail

```js id="o9kt6u"
const slow = new Promise((res) => setTimeout(() => res("Slow"), 2000));
const fast = new Promise((res) => setTimeout(() => res("Fast"), 1000));
const fail = Promise.reject("Error");

Promise.any([slow, fast, fail]).then(console.log);
```

🧠 Output:

```text id="4l0hqx"
Fast
```

👉 First success wins

---

### ⚠️ Example 3: Non-Promise Values

```js id="j3f3u2"
Promise.any([1, Promise.reject("Error")]).then(console.log);
```

🧠 Output:

```text id="fy5gj9"
1
```

👉 Non-promises treated as resolved

## 🔹 When to Use / When NOT to Use

---

### ✅ Use `Promise.any`

- Need **first successful result**
- Can ignore failures
- Want fault tolerance

---

### ❌ Avoid

- When you need all results
  👉 Use `Promise.all`

- When failure matters immediately
  👉 Use `Promise.race`

---

## 🔹 Common Mistakes / Traps

---

### ❌ Mistake 1: Confusing with race

👉 `race` fails fast, `any` does not

---

### ❌ Mistake 2: Not handling AggregateError

👉 Happens when all fail

---

### ❌ Mistake 3: Ignoring background execution

👉 All promises still run

---

### ❌ Mistake 4: Using for dependent tasks

👉 Only for independent tasks
