## 🧠 ES5 vs ES6 (JavaScript)

> ⚠️ This is a **🟡 Conceptual / Interview-favorite topic** → focus on **WHY ES6 was introduced + key differences**

---

## 🔹 Definition

👉 **ES5 (ECMAScript 2009)**

- Older JavaScript standard
- Limited features → verbose, error-prone

👉 **ES6 (ECMAScript 2015)**

- Major upgrade to JavaScript
- Introduced modern features → cleaner, safer, scalable

💡 In simple terms:

> “ES6 fixed many design issues of ES5 and made JS developer-friendly”

---

## 🔹 Core Explanation (Key Differences)

---

## 🟢 1. Variable Declaration

### ES5:

```js
var x = 10;
```

### ES6:

```js
let x = 10;
const y = 20;
```

🧠 WHY:

- `var` → function scoped, causes bugs
- `let/const` → block scoped → safer

👉 ES6 prevents accidental global leaks

---

## 🔵 2. Scope Behavior

### ES5:

```js
if (true) {
  var a = 10;
}
console.log(a); // 10 ❌
```

### ES6:

```js
if (true) {
  let a = 10;
}
console.log(a); // ❌ ReferenceError
```

🧠 WHY:

- ES6 introduces **block scope** → better control

---

## 🟡 3. Functions (Syntax & `this`)

### ES5:

```js
function add(a, b) {
  return a + b;
}
```

### ES6:

```js
const add = (a, b) => a + b;
```

🧠 WHY:

- Arrow functions → shorter syntax
- Lexical `this` → avoids common bugs

---

## 🔁 4. `this` Behavior (Important 🔥)

### ES5 Problem:

```js
function Person() {
  this.name = "Dilip";

  setTimeout(function () {
    console.log(this.name); // undefined ❌
  }, 100);
}
```

### ES6 Fix:

```js
setTimeout(() => {
  console.log(this.name); // Dilip ✅
});
```

👉 Arrow function inherits `this`

---

## 🔥 5. Template Literals

### ES5:

```js
"Hello " + name;
```

### ES6:

```js
`Hello ${name}`;
```

🧠 WHY:

- Cleaner string formatting
- Multi-line support

---

## 🧠 6. Objects Enhancement

### ES5:

```js
var obj = {
  name: name,
};
```

### ES6:

```js
const obj = { name };
```

👉 Property shorthand

---

## 🔄 7. Destructuring

### ES5:

```js
var name = user.name;
```

### ES6:

```js
const { name } = user;
```

🧠 WHY:

- Cleaner extraction
- Less repetitive code

---

## 📦 8. Modules

### ES5:

```js
// No native modules ❌
```

### ES6:

```js
export const a = 10;
import { a } from "./file";
```

🧠 WHY:

- Better code organization

---

## ⚡ 9. Classes

### ES5:

```js
function Person(name) {
  this.name = name;
}
```

### ES6:

```js
class Person {
  constructor(name) {
    this.name = name;
  }
}
```

👉 Cleaner OOP syntax

---

## 🌐 10. Promises

### ES5:

- Callback-based async

### ES6:

```js
fetch(url).then(...).catch(...);
```

🧠 WHY:

- Avoid callback hell

---

| Strings   | Concatenation   | Template literals |
| Objects   | Verbose         | Shorthand         |
| Modules   | ❌              | ✅                |

## 🔹 Example(s) with Code

---

### ✅ ES5 vs ES6 Example

```js
// ES5
var nums = [1, 2, 3];
var doubled = nums.map(function (n) {
  return n * 2;
});
```

```js
// ES6
const nums = [1, 2, 3];
const doubled = nums.map((n) => n * 2);
```

👉 ES6 is shorter + cleaner

## 🔹 Senior-Level Insights 🚀

---

### ⚡ Performance

- ES6 features are mostly syntactic sugar
- No major runtime difference

---

### 🧠 Transpilation

```text
ES6 → Babel → ES5
```

👉 Required for legacy browsers

---

### 🔄 Readability vs Cleverness

❌ Bad:

```js

```

👉 Hard to debug
