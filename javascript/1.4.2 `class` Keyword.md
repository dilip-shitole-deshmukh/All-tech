## 👉 `class` Keyword — Deep-Dive (Interview Ready)

This is a **🟡 Conceptual / Intermediate Topic** → interviewers expect **“syntactic sugar over prototypes” + inheritance + `this` behavior + edge cases**.

---

# 🔹 Definition

- The **`class` keyword** (ES6) provides a **clean, OOP-style syntax** to create objects and handle inheritance.
- Internally, it still uses **JavaScript’s prototype-based system**.

👉 Simple interview line:
**“Classes in JavaScript are syntactic sugar over constructor functions and prototypes.”**

---

# 🔹 Core Explanation

---

## 🔸 1. Basic Class Structure

### ✅ Explanation

- A class contains:
  - `constructor()` → initializes object
  - methods → shared via prototype

- Must be instantiated using `new`.

### 💻 Example

```js id="r5h6n1"
class Person {
  constructor(name) {
    this.name = name;
  }

  greet() {
    console.log(`Hello ${this.name}`);
  }
}

const p = new Person("Dilip");
p.greet(); // Hello Dilip
```

👉 Methods are stored on **prototype**, not per instance

---

## 🔸 2. Class = Constructor + Prototype

### ✅ Explanation

- Under the hood, class behaves like:

```js id="b6f4n8"
function Person(name) {
  this.name = name;
}

Person.prototype.greet = function () {
  console.log(this.name);
};
```

👉 WHY:

- JavaScript is **prototype-based**, not classical OOP

---

## 🔸 3. Constructor Function

### ✅ Explanation

- `constructor()` is automatically called when using `new`.
- Used to initialize instance properties.

👉 Only **one constructor** allowed per class

---

## 🔸 4. Methods Are Non-enumerable

### ✅ Explanation

- Class methods are not enumerable (unlike object methods).
- They don’t appear in `for...in` loops.

👉 WHY:

- Cleaner iteration and avoids unnecessary exposure

---

# 🔹 Inheritance (`extends`, `super`)

---

## 🔸 Core Explanation

- Classes support inheritance using `extends`.
- `super()` calls parent constructor.

---

### 💻 Example

```js id="3xk4m2"
class Animal {
  constructor(name) {
    this.name = name;
  }

  speak() {
    console.log("Animal sound");
  }
}

class Dog extends Animal {
  constructor(name) {
    super(name);
  }

  speak() {
    console.log("Bark");
  }
}

const d = new Dog("Tommy");
d.speak(); // Bark
```

👉 `Dog` inherits from `Animal`

---

# 🔹 Important Concepts

---

## 🔸 1. `this` in Class

### ✅ Explanation

- `this` refers to the **current instance**.
- Must use `this` to access instance properties.

---

## 🔸 2. Strict Mode by Default

### ✅ Explanation

- Classes always run in **strict mode**.
- Prevents accidental global variables.

---

## 🔸 3. Not Hoisted Like Functions

### 💻 Example

```js id="d4m8w2"
const p = new Person("Dilip"); // ❌ ReferenceError

class Person {}
```

👉 Classes are hoisted but in **TDZ** (Temporal Dead Zone)

---

# 🔹 Tricky / Edge Cases

---

## ⚠️ Case 1: Cannot Call Without `new`

```js id="z7v3n9"
class Person {}
const p = Person(); // ❌ TypeError
```

👉 Must use `new`

---

## ⚠️ Case 2: Methods Not Bound

```js id="q3m2b1"
class Person {
  constructor(name) {
    this.name = name;
  }

  greet() {
    console.log(this.name);
  }
}

const p = new Person("Dilip");
const fn = p.greet;
fn(); // undefined ❗
```

👉 `this` lost → same issue as normal functions

---

## ⚠️ Case 3: Arrow Function Fix

```js id="k8n1t5"
class Person {
  constructor(name) {
    this.name = name;
  }

  greet = () => {
    console.log(this.name);
  };
}
```

👉 Arrow binds `this` lexically

# 🔹 Interview Q&A

---

### 1. What is class in JavaScript?

- ES6 feature for creating objects using OOP syntax.
- Internally uses prototypes.

---

### 2. Is class different from constructor function?

- No, it’s syntactic sugar.
- Both work on prototype-based inheritance.

---

### 3. What is constructor in class?

- Special method for initialization.
- Called when object is created.

---

### 4. What is `extends`?

- Used for inheritance.
- Child class inherits parent properties.

---

### 5. What is `super()`?

- Calls parent constructor.
- Required in child class constructor.

---

### 6. Are class methods stored per instance?

- ❌ No
- Stored on prototype → shared

---

### 7. Are classes hoisted?

- Yes, but not usable before declaration (TDZ).

---

### 8. Can class be called without `new`?

- ❌ No
- Throws TypeError

# 🔹 Best Practices

- ✅ Use classes for complex object structures
- ✅ Prefer prototype methods (not inside constructor)
- ✅ Bind methods or use arrow functions when needed
- ✅ Use `extends` for reuse
