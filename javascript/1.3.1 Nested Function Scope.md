# 🧠 Nested Function Scope (JavaScript)

---

## 🔹 Definition

👉 **Simple Definition:**
Nested function scope means **functions defined inside other functions** can access variables from their parent function.

👉 **Slightly Deeper:**
In JavaScript, inner (nested) functions form a **scope chain** with outer functions.
This is based on **lexical scoping**, meaning inner functions remember the environment where they were created.

---

# 🔹 Deep Explanation (Core Section)

---

## 1️⃣ What is Nested Function Scope?

### 🧠 Concept

- A function inside another function is called a **nested function**.
- Inner function has access to:
  - Its own variables
  - Parent function variables
  - Global variables

### ⚙️ Internal working

- When a function is created:
  - It stores a reference to its **outer lexical environment**

- When executed:
  - JS looks for variables in:
    1. Local scope
    2. Parent scope
    3. Global scope

### 💡 Why it behaves this way

- Enables **code reuse + encapsulation**
- Makes closures possible

---

## 2️⃣ Scope Chain in Nested Functions 🔗

### 🧠 How it works

- Each nested function forms a **chain of scopes**
- Variable lookup follows:

  ```
  Inner → Outer → Global
  ```

### ⚙️ Internal behavior

- Each execution context has a reference called:
  👉 `[[OuterEnvironment]]`
- This creates a linked chain

### 💡 Key insight

- JS does NOT search downward → only upward

### ⚠️ Edge case

- If variable not found → `ReferenceError`

---

## 3️⃣ Closures (Most Important 🔥)

### 🧠 What happens

- Inner function retains access to outer variables **even after outer function finishes**

### ⚙️ Internal behavior

- Outer function’s execution context is NOT garbage collected
- Because inner function still references it

### 💡 Why

- Closure = function + preserved lexical scope

### ⚠️ Edge case

- Can cause memory leaks if misused

---

## 4️⃣ Variable Shadowing

### 🧠 What it is

- Inner variable overrides outer variable with same name

### ⚙️ Example

```js
let x = 10;

function outer() {
  let x = 20;

  function inner() {
    let x = 30;
    console.log(x);
  }

  inner();
}
outer();
```

👉 Output: **30**

💡 WHY:
Nearest scope wins

---

## 5️⃣ Private Variables using Nested Scope

### 🧠 Concept

- Variables in outer function become **private**
- Only accessible via inner functions

### 💡 Why important

- Helps create **encapsulation**

# 🔹 Example(s) with Code

---

## ✅ Example 1: Basic Nested Scope

```js
function outer() {
  let a = 10;

  function inner() {
    console.log(a);
  }

  inner();
}

outer();
```

### 🔍 Execution:

1. `outer()` creates execution context → `a = 10`
2. `inner()` defined → linked to `outer` scope
3. `inner()` executes → looks for `a`
4. Finds in parent scope

👉 Output: **10**

💡 WHY:
Scope chain allows access to parent variables

---

## ⚡ Example 2: Scope Chain Lookup

```js
let x = 5;

function outer() {
  let y = 10;

  function inner() {
    console.log(x + y);
  }

  inner();
}

outer();
```

### 🔍 Execution:

1. `inner()` looks for `x` → not found locally
2. Goes to outer → not found
3. Goes to global → finds `x = 5`
4. Finds `y = 10` in outer

👉 Output: **15**

💡 WHY:
Scope chain traversal

---

## 🔥 Example 3: Closure (Interview Favorite)

```js
function outer() {
  let count = 0;

  return function inner() {
    count++;
    console.log(count);
  };
}

const counter = outer();
counter();
counter();
```

### 🔍 Execution:

1. `outer()` runs → `count = 0`
2. Returns `inner` → closure created
3. `counter()`:
   - `count = 1`

4. Next call:
   - `count = 2`

👉 Output:

```js
1;
2;
```

💡 WHY:
Inner function remembers outer scope

---

## 🔥 Example 4: Tricky Shadowing + Closure

```js
function outer() {
  let x = 10;

  function inner() {
    console.log(x);
  }

  let x2 = x;
  x = 20;

  return inner;
}

const fn = outer();
fn();
```

👉 Output:

```js
20;
```

### 💡 WHY:

- Closure captures **reference**, not value
- Updated `x` is used
