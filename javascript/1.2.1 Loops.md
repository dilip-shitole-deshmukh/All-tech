# 🔁 Loops in JavaScript

## `for` | `while` | `do...while`

---

# 🔹 Definition

Loops are control flow statements used to execute a block of code repeatedly until a specified condition evaluates to `false`.

They are fundamental for:

- Iteration
- Data processing
- State transitions
- Algorithm implementation

---

# 1️⃣ `for` Loop

---

## 🔹 Definition

Executes a block of code a specific number of times.

### Syntax

```js
for (initialization; condition; increment / decrement) {
  // code block
}
```

---

## 🔥 Deep Explanation

The `for` loop has **three phases**:

1️⃣ Initialization → runs once
2️⃣ Condition → checked before every iteration
3️⃣ Increment/Decrement → runs after each iteration

---

### Execution Flow

```text
Initialize → Check Condition → Execute Block → Update → Repeat
```

---

## 🔹 Example

```js
for (let i = 0; i < 5; i++) {
  console.log(i);
}
```

---

## 🔥 Scope Behavior (Important)

```js
for (var i = 0; i < 3; i++) {}

console.log(i); // 3 ❗
```

```js
for (let i = 0; i < 3; i++) {}

console.log(i); // ❌ ReferenceError
```

`let` is block scoped → safer.

---

## 🔥 Loop with `break` & `continue`

```js
for (let i = 0; i < 5; i++) {
  if (i === 3) break;
}
```

```js
for (let i = 0; i < 5; i++) {
  if (i === 2) continue;
}
```

---

## 🌍 Real-World Use Cases

✔️ Iterating arrays
✔️ DOM traversal
✔️ Pagination
✔️ Matrix processing
✔️ Performance-critical loops

# 2️⃣ `while` Loop

---

## 🔹 Definition

Executes a block of code **while condition is true**.

### Syntax

```js
while (condition) {
  // code
}
```

---

## 🔥 Deep Explanation

- Condition checked before execution.
- May execute zero times.

---

## 🔹 Example

```js
let i = 0;

while (i < 5) {
  console.log(i);
  i++;
}
```

---

## 🔥 Risk: Infinite Loop

```js
while (true) {
  console.log("Oops");
}
```

Common bug:
Forgetting to update counter.

---

## 🌍 Real-World Use Cases

✔️ Waiting for condition
✔️ Polling APIs
✔️ Game loops
✔️ Input validation loops

# 3️⃣ `do...while` Loop

---

## 🔹 Definition

Executes block **at least once**, then checks condition.

### Syntax

```js
do {
  // code
} while (condition);
```

---

## 🔥 Deep Explanation

Condition evaluated **after execution**.

---

## 🔹 Example

```js
let i = 0;

do {
  console.log(i);
  i++;
} while (i < 5);
```

Even if condition false initially:

```js
let i = 10;

do {
  console.log(i); // Runs once
} while (i < 5);
```

---

## 🌍 Real-World Use Cases

✔️ Menu-driven CLI
✔️ Form retry logic
✔️ At least one execution scenario

# ⚙️ Performance Considerations (Senior-Level)

All basic loops are:

⏱ O(n) for linear iteration
⏱ O(n²) for nested loops

Performance depends on:

- Iteration size
- DOM access inside loop
- Function calls inside loop

---

### ❌ Bad Pattern

```js
for (let i = 0; i < arr.length; i++) {
  document.querySelector("#id"); // expensive
}
```

---

### ✅ Better

Cache outside:

```js
const el = document.querySelector("#id");

for (let i = 0; i < arr.length; i++) {
  // use el
}
```

# 🎓 15+ Senior-Level Interview Q&A

---

### 1️⃣ Difference between `for` and `while`?

`for` → structured iteration
`while` → condition-driven

---

### 2️⃣ When use `do...while`?

When execution must happen at least once.

---

### 3️⃣ What causes infinite loop?

Missing update or wrong condition.

---

### 4️⃣ Why avoid heavy DOM operations inside loops?

Performance degradation.

---

### 5️⃣ How to break nested loops?

Use labels (rare) or refactor logic.

```js
outer:
for (...) {
  for (...) {
    break outer;
  }
}
```

---

### 6️⃣ Which is faster: for or forEach?

Traditional `for` slightly faster.

---

### 7️⃣ Why use `let` instead of `var` in loops?

Block scoping prevents closure bugs.

---

### 8️⃣ What happens with async inside loop?

Common mistake:

```js
for (var i = 0; i < 3; i++) {
  setTimeout(() => console.log(i), 100);
}
```

Prints:

```
3 3 3
```

Because `var` is function scoped.

---

### 9️⃣ Fix async loop issue?

```js
for (let i = 0; i < 3; i++) {
  setTimeout(() => console.log(i), 100);
}
```

---

### 🔟 What is time complexity of nested loops?

O(n²)

---

### 1️⃣1️⃣ Why avoid modifying array length during loop?

Can skip elements or cause infinite loop.

---

### 1️⃣2️⃣ Can `while` be converted to `for`?

Yes, both are interchangeable.

---

### 1️⃣3️⃣ How to optimize loops?

- Minimize operations inside
- Cache length
- Avoid nested when possible

---

### 1️⃣4️⃣ What happens if condition never false?

Infinite loop → UI freeze.

---

### 1️⃣5️⃣ Why modern JS prefers `for...of`?

Cleaner syntax and safer iteration.
