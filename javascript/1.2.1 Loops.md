## 👉 Loops: `for`, `while`, `do...while`

---

## 🔹 Definition

Loops are used to **execute a block of code repeatedly** until a condition is met.

👉 Core idea:
Instead of writing repetitive code, loops help **automate iteration** over data or conditions.

---

## 🔹 Core Explanation

### 🟢 1. `for` Loop

```javascript
for (initialization; condition; update) {
  // code
}
```

- Runs in a **structured way**: initialize → check → execute → update.
- Best when you **know the number of iterations** beforehand.

👉 Why it’s useful:
Everything (counter, condition, update) is in one place → more readable and controlled.

---

### 🟢 2. `while` Loop

```javascript
while (condition) {
  // code
}
```

- Executes **as long as condition is true**.
- Condition is checked **before execution**.

👉 Why it’s useful:
Good when the number of iterations is **unknown** and depends on runtime conditions.

---

### 🟢 3. `do...while` Loop

```javascript
do {
  // code
} while (condition);
```

- Executes **at least once**, then checks condition.
- Condition is checked **after execution**.

👉 Why it’s useful:
Ensures code runs **minimum one time**, even if condition is false.

---

## 🔹 Example(s) with Code

### ✅ Example 1: `for` Loop

```javascript id="2ixph7"
for (let i = 0; i < 3; i++) {
  console.log(i);
}
```

👉 Execution:

- i = 0 → print → increment
- i = 1 → print → increment
- i = 2 → print → increment
- i = 3 → stops

---

### ✅ Example 2: `while` Loop

```javascript id="18eec0"
let i = 0;

while (i < 3) {
  console.log(i);
  i++;
}
```

👉 Explanation:

- Condition checked first
- If false initially → loop never runs

---

### ⚠️ Example 3: `do...while` Difference

```javascript id="yr8zzc"
let i = 5;

do {
  console.log(i);
  i++;
} while (i < 3);
```

👉 Output:

```text
5
```

👉 Why:

- Code runs once before condition check

---

## 🔹 Real-world Use Cases

- 🔹 `for` → iterating arrays (UI lists, table rows)
- 🔹 `while` → polling APIs, waiting for conditions
- 🔹 `do...while` → retry logic (execute at least once)

---

## 🔹 When to use / When NOT to use

### ✅ Use:

- `for` → when iteration count is known
- `while` → when condition-driven loops
- `do...while` → when execution must happen at least once

### ❌ Avoid:

- Infinite loops (missing condition/update)
- Using `while` when `for` is clearer

---

## 🔹 Common Mistakes / Traps

### ❌ Mistake 1: Infinite Loop

```javascript id="9t33t1"
while (true) {
  console.log("runs forever");
}
```

💡 Why:

- Condition never becomes false

---

### ❌ Mistake 2: Forgetting Update

```javascript id="9dhsqb"
let i = 0;
while (i < 3) {
  console.log(i);
}
```

💡 Why:

- `i` never changes → infinite loop

---

### ❌ Mistake 3: Off-by-One Error

```javascript id="2qvh2d"
for (let i = 0; i <= 3; i++) {
  console.log(i);
}
```

👉 Output: 0,1,2,3 (4 values)

💡 Developers often expect 3 iterations

---

### ❌ Mistake 4: Scope Issue with `var`

```javascript id="h1g1tb"
for (var i = 0; i < 3; i++) {}

console.log(i); // 3
```

💡 Why:

- `var` is function-scoped, not block-scoped

## 🔹 Interview Q&A

### ❓ 1. Difference between `for` and `while`?

- `for` → structured, best for known iterations
- `while` → flexible, best for condition-based loops

---

### ❓ 2. When does `do...while` execute?

- Always runs at least once
- Condition checked after execution

---

### ❓ 3. Can a `while` loop not execute at all?

- Yes, if condition is false initially

---

### ❓ 4. What is an infinite loop?

- Loop that never ends due to always-true condition

---

### ❓ 5. Which loop is best for arrays?

- `for` loop (or modern `for...of`)
- Predictable and readable

---

### ❓ 6. Why avoid `var` in loops?

- Scope leaks outside block
- Causes bugs in async operations

---

### ❓ 7. What is loop control?

- Using `break` (exit loop)
- Using `continue` (skip iteration)

---

## 🔹 Advantages / Pitfalls

### ✅ Advantages

- Reduces repetitive code
- Improves readability
- Essential for data processing

### ❌ Pitfalls

- Infinite loops
- Off-by-one errors
- Performance issues in large loops

---

## 🔹 Best Practices

✔ Use `let` instead of `var` in loops
✔ Keep loop logic simple and readable
✔ Avoid deeply nested loops
✔ Use `break`/`continue` carefully
✔ Prefer array methods (`map`, `filter`) when possible

---

## 🔹 Senior-Level Insights (Light)

- Large loops can block UI → consider:
  - Breaking into chunks (`setTimeout`, `requestIdleCallback`)

- Avoid unnecessary iterations → optimize conditions
- Prefer functional methods (`map`, `reduce`) for cleaner code

---

## 🔹 Final Summary (Interview Ready)

- `for` → best for known iterations
- `while` → condition-based looping
- `do...while` → runs at least once

💡 **Golden Insight:**
👉 “Choose loop based on clarity — not just functionality. `for` for control, `while` for flexibility, `do...while` for guaranteed execution.”
